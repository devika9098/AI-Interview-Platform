# AI Interview Platform

An AI-powered interview preparation platform designed to help students practice interviews, improve their skills, and prepare for placements.

## Features

- User Registration and Login
- AI-based Interview Practice
- Interview Performance Analytics
- Resume Upload
- Interview Preparation Roadmaps
- Speech-to-Text Support
- Interactive Dashboard

## Tech Stack

**Frontend**
- React.js
- Tailwind CSS
- Recharts

**Backend**
- Node.js
- Express.js
- MongoDB
- JWT Authentication

**AI & Other Technologies**
- Python
- FastAPI
- WebSockets
- Ollama

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/devika9098/AI-Interview-Platform.git
```

### 2. Backend Setup

```bash
cd AI-Interview-Platform/BACKEND
npm install
npm run dev
```

### 3. Frontend Setup

Open another terminal:

```bash
cd AI-Interview-Platform/FRONTEND
npm install
npm run dev
```

### 4. Environment Variables

Configure your backend `.env` file with the required MongoDB connection string and JWT secret. Keep credentials private.
